## Notes that affect how the data may be used

- **drugcomb**: The bulk table has no study or tissue column: rows cannot be traced back to O'Neil, ALMANAC, etc. without the DrugComb API.
- **tdc**: The `drugcomb` set is the NCI-60 (ALMANAC) part of DrugComb, so it overlaps the DrugComb connector. `oncopolypharmacology` is the O'Neil screen (1.6 GB file).
- **oneil**: Publishes Loewe synergy only. Each row is already averaged over replicates.
- **nci_almanac**: Reports its own ComboScore, not Bliss / Loewe / HSA / ZIP. robots.txt of wiki.nci.nih.gov disallows /download/, so the file is placed manually.
- **depmap**: Pinned to release 24Q4. Change `article_id` and `version` together to upgrade.
- **gdsc**: cancerrxgene.org is retired (HTTP 410); data now lives in Cell Model Passports.
- **ddinter**: Clinical interaction severity (Major / Moderate / Minor), not synergy.
- **drugbank**: Reads the `drugbank vocabulary.csv` export. Nothing is ever downloaded.
- **pubchem**: Resolves the drug names found in the synergy tables. Runs after stage 1.
- **chembl**: Looks up the InChIKeys PubChem returned; names PubChem missed are tried by name.
- **pubmed**: Queries are built from the processed drug table, so run `clean` first.
- **pubmed_baseline**: List the file numbers to fetch in `options.files`; the default is none. The server answers `Disallow: /` in robots.txt, so files are placed manually.
- **europepmc**: Runs after PubMed. Adds `is_open_access` and fills abstracts PubMed lacks.
- **pubtator**: Chemical / gene / disease mentions, useful to cross-check the offline matcher.
